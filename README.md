# シンプルGPS計器（instrument-tool）

ブラウザで動作する、シンプルなGPS計器アプリです。
GPS情報と端末センサーを使って、速度・高度・方位・昇降率・姿勢角を表示します。

## 主な機能

- **SPD**: 速度（knot / km/h）
- **ALT**: 高度（ft / m）
- **HDG**: 方位（°）
- **VSPD**: 昇降率（ft/min / m/s）
- **ANGLE**: 端末姿勢（Pitch / Roll）
- **ZERO**: 姿勢角の零点補正
- **PWA対応**: ホーム画面追加・オフライン起動（Service Workerキャッシュ）

## 動作要件

- HTTPS環境（または localhost）
- 位置情報（Geolocation API）が使える端末/ブラウザ
- 角度表示には DeviceOrientationEvent 対応端末が必要
  - iOS系ブラウザでは、ユーザー操作後に権限許可が必要です

## 使い方

1. ページを開くとGPS監視が始まります。
2. `ANGLE ON` を押すと角度センサーを有効化します。
3. `ZERO` で姿勢角の基準を現在値に合わせられます。
4. PWAとして「ホーム画面に追加」すると、次回以降はオフラインでも起動可能です。

## 補足

- 本アプリはクライアントサイドで動作し、外部サーバーへのデータ送信を前提としていません。
- センサーの取得可否・精度は、端末やブラウザ実装に依存します。
